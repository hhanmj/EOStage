# Sentinel-1 SAR 方法边界与线性功率运算规范

`COPERNICUS/S1_GRD` 集合在 GEE 入库时已完成轨道校正、热噪声去除、辐射定标、地形几何正射（Orthorectification）并转为分贝值（dB），但**集合内部高度异质**且**标准入库流程未执行辐射地形平坦化（Radiometric Terrain Flattening）**。

## 1. 严禁二次定标与混合几何比较

- **禁止重复转 dB**：`COPERNICUS/S1_GRD` 数值已是 dB；若计算线性比值或线性域滤波，须先显式转回线性功率 `power = 10 ** (dB / 10)`，或改用浮点原始线性功率集合 `COPERNICUS/S1_GRD_FLOAT`。
- **同质化锁定五要素**：严肃的多期对比或洪水前后差分必须先过滤锁定：
  1. 成像模式：`instrumentMode == "IW"`（常见陆地场景）；
  2. 分辨率：`resolution_meters == 10`；
  3. 极化组合：`transmitterReceiverPolarisation` 同时包含所需极化（常见 `VV`、`VH`）；
  4. 升降轨方向：`orbitProperties_pass` 固定单一 `ASCENDING` 或 `DESCENDING`；
  5. 相对轨道号：严格变化检测需尽量锁定同一 `relativeOrbitNumber_start`。
- **升降轨禁止混算**：不同视角下的城市二次散射、山体叠掩和阴影方向相反，混用升降轨会把**观测几何差异伪装成地面变化**；若单轨覆盖不全，应分轨道组独立建模后再整合。

## 2. 分贝（dB）与线性域（Linear Power）运算铁律

- **前后变化量（对数比值）**：在 dB 域直接相减 `post_db.subtract(pre_db)` 等价于线性功率比的对数（$10 \log_{10}(P_{\text{post}} / P_{\text{pre}})$），物理含义明确。
- **严禁 dB 直接相除**：`post_db / pre_db` 在跨越正负分贝时会失去物理量纲意义；凡需比值或物理能量平均（如均值/相干斑线性统计），必须转换至线性域运算后再按需回转 dB：

```python
def db_to_power(img: ee.Image) -> ee.Image:
    return ee.Image(10).pow(img.divide(10))
```

- 任何筛选阈值、比值指标与空间滤波，必须在说明中明确标注作用在 **dB 域**还是**线性功率域**。

## 3. 相干斑、入射角与山区地形局限

- **优先多时相中值/均值抑制相干斑**：在几何锁定后的多景堆栈上做时序中值合成，通常比未论证参数的空间盒式/Lee 滤波更不易损失细窄河道边界。若使用空间滤波，须记录窗口尺寸、域（线性/dB）和分辨率代价。
- **`angle` 波段认知边界**：GRD 自带的 `angle` 是相对参考椭球面的近似局部入射角，适合用于剔除近远距边缘条带异常，**但无法证明已经消除了真实起伏地形带来的辐射畸变**。
- **山区陷阱**：正射校正不能消除雷达叠掩（Layover）、透视收缩（Foreshortening）和雷达阴影（Shadow）；山地洪水制图需叠加 DEM 坡度/坡向遮罩并在结论中标出盲区范围。

## 4. 洪水与变化提取 5 步交付标准

1. 前后期采用完全一致的模式、极化、升降轨、相对轨道、季节窗与统计量（Reducer）。
2. 同时输出灾前底图、灾后底图、变化差值/比值图、`angle` 检查图与候选掩膜层。
3. 诸如 `VV < -16 dB` 仅可作为**初始候选阈值**，必须结合局部直方图、参考样本检验确定区域阈值。
4. 显式讨论或剔除永久水体（如 `JRC/GSW1_4/GlobalSurfaceWater`）、山体雷达阴影、风浪 roughened water、密林体积散射与城区建筑强二次散射混淆。
5. 如涉及面积或精度报告，须列出前后有效过境景数并用独立高分光学影像或样本完成验证；同时明确：**SAR 能穿云，但无法还原被云遮挡位置的光学色彩或真实地表光谱反射率**。
