# Landsat 与 Sentinel-2 去云方法边界与控制对照准则

本卡聚焦光学传感器去云算法的适用前提、常见误解及实验评估标准，与具体配方代码互补。

## 1. Landsat Collection 2 Level-2 去云方法选择

### 默认推荐基线
- **主数据源**：优先采用 `LANDSAT/LC08/C02/T1_L2`、`LANDSAT/LC09/C02/T1_L2`（历史长序配 `LE07` / `LT05` C2 L2）；**严禁沿用已下线的 Collection 1 波段名 `pixel_qa` 与旧定标系数**。
- **双字段联动**：使用 `QA_PIXEL`（CFMask 算法家族产出的业务质量位掩膜）联合 `QA_RADSAT == 0` 屏蔽辐射饱和像元；仅当研究目标明确需要高亮冰雪或饱和目标时，方可显式放开 `Bit 5`（Snow）或 `QA_RADSAT` 约束并在元数据中注明。
- **元数据与像元级区分**：整景属性 `CLOUD_COVER` 仅用于初期粗筛景列表，**绝非像元级云掩膜**；低整景云量仍可能包含局部厚云、薄卷云与长云影。
- **定标解耦**：定标系数（`SR_B. * 0.0000275 - 0.2`，`ST_B10 * 0.00341802 + 149.0`）应与 `QA_PIXEL` 掩膜逻辑清晰分离，避免未减去 `-0.2` 偏移就直接计算比值植被指数。

### 方法对比边界
| 方法 | 适用定位 | 已知风险与限制 |
| --- | --- | --- |
| `QA_PIXEL` + `QA_RADSAT == 0` | C2 L2 科研生产默认方案 | 高亮屋顶/盐碱地/积雪易被误判，薄卷云和远端云影存在不确定性 |
| `ee.Algorithms.Landsat.simpleCloudScore` | 仅限 TOA 影像快速目视对比或教学演示 | 非稳健高精度云检测器，禁止作为 C2 L2 定量分析主掩膜 |
| 单纯 `CLOUD_COVER` 过滤 | 景级预筛减少计算图规模 | 保留景内云与云影，直接合成易引入云污染偏高异常 |

## 2. “去云掩膜”与“云下重建”不可混淆

- **去云掩膜**仅将污染像元置为空值（Mask），**不会还原被厚云遮挡时刻的真实地表反射率**。
- 当用户提出“去云后把空洞补齐”或“重建云下影像”时，必须明确指出这属于**第二阶段的时空缺口填补或数据融合任务**（例如多日时序合成、谐波/HANTS 拟合或 Landsat-MODIS 贝叶斯时空融合），且重建值属于模型估算而非实际卫星直测；同时需确认目标形态（单景填补、季节合成或连续时间序列）。

## 3. Sentinel-2 四类去云算法的控制变量对照规范

在评估 `QA60`、`SCL`、`COPERNICUS/S2_CLOUD_PROBABILITY`（s2cloudless 风格概率）与 `Cloud Score+` (`GOOGLE/CLOUD_SCORE_PLUS/V1/S2_HARMONIZED`) 差异时，必须遵循以下控制实验标准：

1. **变量锁定**：固定同一单景、同一小范围 AOI、同一尺度（如 10 m）和统一显示拉伸（如 `B4/B3/B2` 原始 DN `0..3000`）；不得用多时相合成结果对比单法优劣，否则会把日期差异和云况差异混淆为算法差异。
2. **四法机理特征**：
   - `QA60`：仅含不透明云与卷云位元，缺失独立云影判定，保留像元偏多但漏检云影与薄霾；且在 `2022-01-25` 至 `2024-02-28` 存在历史缺口，**禁止跨年长序列单独依赖 `QA60`**。
   - `SCL`：依赖 Sen2Cor 场景分类（剔除 `3, 8, 9, 10` 及可选 `11`），可排除部分云影但容易误杀暗水体与建筑阴影。
   - `s2cloudless`：基于 10 m 云概率（如 `probability < 40`）配合暗 NIR 像元与太阳方位角投影云影，阈值过松漏薄云、过严损有效率。
   - `Cloud Score+`：输出连续晴空可用评分（常用 `cs_cdf >= 0.60` 或多云区 `0.50`），对云边缘与薄雾过渡最敏感，现为通用合成首选。
3. **科学解释红线**：“保留清晰像元比例”与“同 `Cloud Score+` 空间一致率”仅反映掩膜行为保守度，**不等于分类精度**。评价真实精度需对照独立人工标注真值，报告 Precision / Recall / Omission / Commission 指标。
