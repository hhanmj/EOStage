# 研究区边界处理与分块计算安全边界

当研究区几何复杂（顶点过多、跨岛屿孔洞、条带狭长）或覆盖面积较大时，粗暴的过滤、逐景裁切或盲目切片都会导致 GEE 计算图膨胀、配额暴涨甚至科学失真。

## 1. 边界记录六维度检查

在触发高开销计算或导出前，应明确并向用户确认以下边界状态：

1. **AOI 来源**：地图交互绑定区（Working AOI）、行政区划几何、用户上传矢量、显式经纬度包络框 `bbox`，还是全球范围；**严禁在缺失 AOI 时静默代换固定城市坐标**。
2. **精度要求**：仅需矩形外包框 `bbox` 粗筛，还是统计/导出阶段必须严格遵循精确多边形边界。
3. **几何复杂度风险**：要素数量、顶点数、孔洞、多面体（MultiPolygon）及无效自相交风险。
4. **过滤几何与精算几何分离**：
   - 集合级粗过滤优先使用简化外包框 `collection.filterBounds(roi.bounds())`；
   - 最终 `reduceRegion`、`reduceRegions` 面积统计和 `Export` 边界使用精确几何（必要时先验证有效性）。
5. **禁令清单**：
   - 禁止在集合 `map()` 内对每一景提前调用 `.clip(roi)`（留到最终产物再裁切，避免阻碍计算图优化）；
   - 禁止对超大 `FeatureCollection` 直接 `.geometry()` 并合并求交（易爆节点内存），优先逐要素 `reduceRegions`；
   - `reduceRegion` 必须显式给出 `geometry`、`scale` 与 `maxPixels`（大区域配合说明 `tileScale` 与 `bestEffort` 取舍）。

## 2. 算法可独立切块性（Tile Safety）判定准则

大区域往往需要多块切片后拼接交付，但**并非所有遥感算法都能分块各自算再直接拼接**。切块前必须判断算法归属：

### 安全可切块（Tile-Safe）
- 逐像元光谱指数（NDVI、NDWI、MNDWI、EVI、NBR、SAVI 等）；
- 相同日期与掩膜规则下的逐像元云端合成（`median`、`mean`、`qualityMosaic`）；
- 基于固定已知模型推理结果的逐像元时序斜率/趋势；
- 带足够像元重叠缓冲区的局部邻域卷积滤波（含坡度/坡向等局部核，只要每块带边缘保护）。

### 禁止或高危切块（Tile-Unsafe，不可直接本地分块拼接）
以下依赖**全局统计基线或跨边界空间连通**的算法，若切片独立运算会产生块间色阶跳变、主成分方向不一致或统计断裂：
- **全局 PCA / 遥感生态指数 RSEI（`pca_rsei`）**：协方差矩阵与特征向量必须基于全研究区联合计算，分块算会导致每块主轴反转或均值偏移；
- **全区归一化 / 全局分区统计（`global_zonal_stats`）**：全局最值、百分位拉伸或整区汇总指标不可按块各自归一化；
- **图像分割 / 连通域标记 / 区域生长 / 流域提取（`segmentation`、`connected_components`、`watershed`）**：跨块边界的目标与水系将被强行截断；
- **样本分布随位置变化的现场监督分类训练（`ml_training`）**：切块内样本不全会导致分类器偏置。

**处置规范**：EOStage 的预演卡（`gee_export_preflight`）会把上述类型标为 `tile_unsafe`；一旦块数 `> 1`，自动建议走**全区统一构图 + 外部批量导出通道**（Drive / Cloud Storage / EE Asset），或先缩小研究区 / 明确改为统一粗尺度预览，绝不在后台擅自拆块破坏算法一致性。

## 3. 安全分块导出设计最低要素

如确需按网格切片交付大图幅，运行前必须核清：网格 CRS、单片像素尺寸、总分块数、边缘是裁切还是全格网输出、像素类型与 `nodata` 定义、任务前缀以及下游拼接规则（如本地 GDAL VRT 虚拟镶嵌转单幅 GeoTIFF）。
