# 快速开始

ASF 数据集共用“资源下载 → 在线检索”中的一个 SAR 工作台。Dataset 为单选；
切换后，平台、产品/处理级别、成像模式、极化和任务专用范围会按数据集能力更新，
不适用字段会禁用。检索后在同一个工作台勾选产品、选择目录并创建下载任务。
默认直接写入所选目录；如需归档可勾选“按产品/处理级别建立子目录”。

这份文档面向第一次使用 EOStage 的用户，目标是帮你完成一次标准的数据准备流程。

## 1. 准备账号

首次使用建议先进入“设置”：

- Earthdata / ASF：用于 Sentinel-1 检索和下载。
- OpenTopography：用于 DEM 下载。
- 网络代理：如果你的网络无法直接访问数据源，可以在这里配置。
- 缓存目录：默认启用，用于保存任务状态、日志和必要缓存。

软件不会内置公共账号或密钥。每位用户都应使用自己的账号，并遵守对应数据源网站的使用规则。

## 2. 选择 AOI

AOI 可以来自：

- 地图手动绘制。
- 全球地名/行政区搜索后预览的真实边界。
- 中国省、市、区下拉选择后的 DataV 边界；台湾下级行政区在需要时使用
  Nominatim 的真实 Polygon/MultiPolygon。
- 本地边界文件。
- 手动经纬度范围。

搜索框是全球搜索，只在点击搜索或按 Enter 后请求，不会把关键词自动追加为“中国”。
搜索和预览不要求先建立研究区；确认地图上的结果后，再打开工作区、项目和研究区，
点击“绑定为研究区 AOI”才会写入 Store。桌面版内置索引只作为中国下拉选项回退，
不把 bbox 冒充行政边界；无法取得真实 Polygon/MultiPolygon 时应改用其他结果或上传
权威 GeoJSON/SHP。

## 3. 检索 SAR 数据

进入资源下载后：

1. 选择 ASF Dataset；Sentinel-1、Burst 和历史任务使用同一个入口。
2. 设置日期、轨道方向、产品类型、极化等筛选条件。
3. 点击检索。
4. 在地图中查看影像范围，在列表中确认元数据。
5. 在 SAR 工作台勾选要下载的影像。

如果检索数量较多，优先选择覆盖率更高的数据可以减少无效下载。

### NISAR L-band 与 S-band 使用说明

按 L-band 和 S-band 分开检查，不能把两条路径混在一起：

**L-band（可以执行真实检索）**

1. 打开 `EOStage.exe`，在顶部筛选中选择 NISAR L-band。
2. 点击“检索”，等待结果列表和地图更新。
3. 在结果中选择“完整产品”进行完整下载，或选择“AOI 裁剪”。
4. 如果选择 AOI 裁剪，在裁剪界面选择影像、AOI、Frequency 和 Polarization。
5. 检查结果、排除项和共同能力，确认选择符合预期。
6. 选择并确认输出目录（建议使用剩余空间充足的独立目录）。
7. 点击“创建”确认任务，然后逐景查看任务详情及准备、规划、下载、生成、校验状态。

**S-band（正式准入前只检查入口）**

1. 在顶部筛选中选择 NISAR S-band。
2. 只确认筛选入口可见，并显示“正在接入”“禁用”或明确拒绝。
3. 在正式准入前，不得点击“检索”或等待结果，不得选择产品、进入裁剪、选择输出目录、创建任务或真实下载。

## 4. 下载与恢复

下载任务进入下载中心后，可以查看：

- 当前速度和进度。
- 并发中的文件。
- 暂停、继续、结束、重试。
- 每个任务的详细日志。

软件会保存任务状态。重启后，暂停任务应继续停留在任务队列；结束、失败、超时任务进入历史记录，可按需恢复或重试。

## 5. 准备轨道和 DEM

- 精密轨道会根据 Sentinel-1 影像匹配 POEORB/EOF。
- DEM 可仅下载，也可下载后转换椭球高。
- DEM/GDAL 高级转换组件按需安装，不默认塞进主程序。

## 常见误区

- EOStage 不做完整 InSAR 解算。
- 没有账号或 API Key 时，不应开始真实下载。
- 代理只影响需要联网的数据源，不改变本地文件处理。
- SARscape 对 DEM 命名和格式有特定要求，转换前请确认目标软件流程。
