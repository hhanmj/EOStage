# Superseded Dataset Registry Draft Fixtures

These fixtures belong to the scene-only Dataset Registry design dated
2026-08-06. They are retained only as historical design provenance.

They are not current implementation authority, must not be used to generate
runtime code or tests, and must not be extended for new resources. The active
authority is:

- `contracts/v3/resource-registry.schema.json`;
- `contracts/v3/resource-registry.v1.json`.

The umbrella Resource Registry supersedes the old fixture schema and T1–T4
task chain. Existing JSON files in this directory intentionally remain
unchanged so the historical proposal can still be audited.
